# Homebrew Tap for graphene

This is a [Homebrew tap](https://docs.brew.sh/Taps) for [graphene](https://github.com/aitorvs/graphene-releases), a CLI tool for stacked pull requests with git and GitHub.

## Installation

```bash
brew tap aitorvs/graphene
brew install graphene
```

## Usage

Once installed, the `gt` command will be available:

```bash
gt --help
```

## About

graphene (`gt`) helps you manage stacked git workflows, making it easy to create, modify, and submit chains of dependent pull requests on GitHub.

For full documentation and tutorials, see the [graphene-releases repository](https://github.com/aitorvs/graphene-releases).

---

**Note:** This repository contains only the Homebrew formula. Prebuilt binaries and documentation are maintained in [aitorvs/graphene-releases](https://github.com/aitorvs/graphene-releases).
